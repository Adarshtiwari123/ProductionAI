This document provides an overview of the project structure and explains the working of each file in the project.

## Project Structure Overview

The project is a Streamlit-based web application that simulates an AI-driven interview (LISA). It includes voice interaction (speech-to-text and text-to-speech), dynamic question generation based on the user's resume, and a scoring system.
